Guía de Inicio Rápido

                        
Aprende a configurar tu navegador para interceptar tráfico con AetherProxy.

                    

                


                

                    

                        
1. ¿Cómo funciona AetherProxy?

                        
AetherProxy actúa como un "intermediario" o Proxy local. Cuando tu navegador realiza una petición web (HTTP), esta pasa primero por AetherProxy. Si la interceptación está activa, la petición se detiene aquí y puedes modificarla antes de dejarla seguir su camino.

                    


                    

                        
2. Configurar tu Navegador (Firefox Recomendado)

                        
    
                            
  1. Abre Firefox y ve a Ajustes / Ajustes de Red (al final de la página General).
    2. 
                            
  2. Haz clic en Configuración...
    3. 
                            
  3. Selecciona Configuración manual de proxy.
    4. 
                            
  4. Ingresa en Proxy HTTP: 127.0.0.1 y en Puerto: 8080.
    5. 
                            
  5. Marca la opción "Usar este proxy para HTTPS también".
    6. 
                            
  6. Haz clic en Aceptar.
    7. 
                        

                        

                            
                            Nota: Como este es un proxy de aprendizaje sencillo, las conexiones HTTPS se tunelizarán de forma segura (pasante) sin ser leídas por seguridad. Para interactuar con HTTPS libremente sin alertas SSL, utiliza la pestaña de Repeater.
                        

                    


                    

                        
3. Probando la Interceptación HTTP

                        
    
                            
  1. Activa el interruptor en la pestaña Interceptar.
    2. 
                            
  2. En tu navegador configurado, visita un sitio HTTP simple como: http://httpbin.org.
    3. 
                            
  3. Verás que la página queda cargando en el navegador, y aparecerá en la pestaña Interceptar de AetherProxy.
    4. 
                            
  4. Modifica los headers o la ruta de la petición y presiona Forward para ver el efecto.
    5. 
                        

                    


                    

                        
4. Interceptar Tráfico Local (localhost / 127.0.0.1)

                        
Por seguridad y rendimiento, los navegadores modernos evitan usar el proxy para conexiones dirigidas a localhost o 127.0.0.1 de manera predeterminada. Si estás desarrollando y quieres interceptar tu aplicación local:

                        
    
                            
  1. Abre Firefox y escribe about:config en la barra de direcciones.
    2. 
                            
  2. Busca la opción network.proxy.allow_hijacking_localhost.
    3. 
                            
  3. Haz doble clic sobre ella para cambiar su valor a true.
    4. 
                            
  4. Ve a Ajustes de Red en Firefox y asegúrate de eliminar localhost y 127.0.0.1 de la lista "No usar proxy para" (No proxy for).
    5.
